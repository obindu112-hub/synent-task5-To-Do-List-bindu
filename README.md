To-Do List Web Application

About the Project

This project is a To-Do List Web Application developed as Task 5 of the Synent Technologies Web Development Internship. It helps users organize daily activities and manage tasks through a simple, interactive interface.

Features

- Add Tasks: Add new tasks to the task list.
- View Tasks: View added tasks in an organized list.
- Mark as Completed: Mark tasks as finished.
- Delete Tasks: Remove tasks that are no longer needed.
- User-Friendly Interface: Simple and attractive design.
- Responsive Design: Layout designed to work on different screen sizes.

Technologies Used

- HTML5: Creates the structure of the application.
- CSS3: Provides styling, colors, and layout.
- JavaScript: Handles task operations and user interactions.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Add tasks and test the available features.
